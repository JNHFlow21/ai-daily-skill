# TechFiDaily RSS Sources (English, Hot News Only)

Constraints:
- English only
- Hot news / headlines (no blogs)
- No exchange announcement feeds
- Prefer stable RSS / official newsroom RSS

Note: The list is intended to be edited over time. Treat this file as the single source of truth for what to fetch.

## Tech

- BBC Technology: `https://feeds.bbci.co.uk/news/technology/rss.xml`
- Ars Technica RSS index: `https://arstechnica.com/rss-feeds/`
- WIRED RSS index: `https://www.wired.com/about/rss-feeds/`
- The Register RSS index: `https://www.theregister.com/Design/page/feeds.html`
- Hacker News: `https://news.ycombinator.com/rss`
